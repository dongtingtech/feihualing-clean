## 项目文件地图

```
audio_pipeline/
├── scripts/            ← 全部代码（VSCode 打开这个目录写代码）
│   ├── config.py                总开关：所有参数集中在这
│   ├── check_env.py             D1 环境体检
│   ├── d0_make_test_audio.py    合成测试音频（数据没到位也能跑通流程）
│   ├── d2_format_and_filter.py  D2 格式归一+质量过滤（海关安检）
│   ├── d3_split_denoise_loudness.py  D3 VAD切分+谱减降噪+响度归一
│   ├── d4_transcribe.py         D4 Whisper 转写+文本清洗
│   ├── d5_dedupe_manifest.py    D5 去重+manifest+总结
│   └── run_all.py               一键跑通 D2→D5
├── data/raw/           ← 【把你的真实音频放这里】
├── data/clean/         ← D2 产出的 16kHz 统一格式
├── output/segments/    ← D3 切出的语段
├── output/transcripts.jsonl / manifest.jsonl ← D4/D5 产物
├── reports/            ← 每个环节的清洗报告（多少进/出/为什么）
├── tools/              ← ffmpeg 便携版（自动解压，无需配置）
└── docs/               ← 讲义（概念先修课、实操指南）
```
